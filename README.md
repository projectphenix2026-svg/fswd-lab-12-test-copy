# Student Services Dashboard

The project of Full Stack Web Development, Lab 12. The app is finished. In the lab you give it a version,
publish it with GitHub Pages, upgrade it, and take a bad release back.

1. This is your own copy. Wait until the terminal below has fetched the packages and shows a line that ends in `$`.
2. Run `npm run dev`. A preview opens with the dashboard: eight services, one card each. Stop it with Ctrl + C.
3. Go back to the lab page and follow it, one card at a time. Every command you need is printed on its card.
4. Each card ends with a check, such as `npm run check l12-D1 K7QF`. Copy it from the card: the last word is the card's own key.
5. The check prints `ok` lines, or `NOT YET` with what to put right. When all is right it prints a result code for the card.

The files you change: `src/version.js`, `src/Footer.jsx`, `src/features.js`, `CHANGELOG.md`, and two small files in `drills`.
The folder `steps` holds the commands of the cards that are done in the terminal. Everything else is given: leave it as it is.
